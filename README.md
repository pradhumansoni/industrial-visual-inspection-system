## Project Vision

This project is not built to maximize benchmark accuracy alone.

Its objective is to design, develop, and deploy a scientifically validated Industrial Visual Inspection System that combines modern deep learning with statistical rigor, explainability, reliability, and production engineering.

The system follows the philosophy:

> **Think like a Research Scientist. Build like an ML Engineer. Deploy like an MLOps Engineer.**

---

## Project Goals

This project aims to:

- Understand industrial image datasets scientifically.
- Develop and compare modern computer vision architectures.
- Apply rigorous statistical validation to every major experiment.
- Build trustworthy AI through explainability and confidence estimation.
- Evaluate robustness under real-world conditions.
- Deliver a production-ready industrial inspection application.

# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt
